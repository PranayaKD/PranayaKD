### 👨‍💻 About Me

I am a **Python Full-Stack & Backend Engineer** who architects resilient, high-throughput web systems, production-grade REST APIs, and database-intensive applications. My focus centers on clean architecture, eliminating concurrency issues, database query optimization (indexing & N+1 elimination), and shipping reliable products.

- 🚗 **Flagship Project**: **[Rentora](https://github.com/PranayaKD/Rentora)** — Production automotive rental platform with 275 passing unit tests, atomic double-booking prevention, dynamic pricing, and FASTag reconciliation.
- 🛒 **Core Commerce**: **[ShopperMart](https://github.com/PranayaKD/ShopperMart)** — Full-featured e-commerce system with UUID-backed entity security, guest-to-user cart migration, and Razorpay integration.
- ⚡ **Backend Mastery**: Python, Django, Django REST Framework (DRF), FastAPI, PostgreSQL, MySQL.
- 💬 **Ask me about**: Concurrency & transactions, ORM optimization, REST API design, authentication state machines, and payment webhooks.
